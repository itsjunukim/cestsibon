## 시작하기

### 로그인

1. 브라우저에서 시스템 주소로 접속
2. 로그인 페이지에서 **이메일** 입력
3. **비밀번호** 입력
4. **로그인** 버튼 클릭

## 대시보드 보기

**경로**: 로그인 후 메인 화면 또는 좌측 메뉴 > 대시보드

### 화면 구성

```
┌────────────────────────────────────────┐
│ 영업 현황 대시보드                      │
│ [오늘] [이번 주] [이번 달]              │
├────────────────────────────────────────┤
│ 📊 총 매출        📈 예약        👥 방문객 │
│ ₩ ___,___        ___ 건         ___ 명   │
│ (PIN 잠금 🔒)                          │
├────────────────────────────────────────┤
│ 매출 추이 (차트)                        │
│ [날짜 클릭 시 해당 예약 목록 확인]      │
└────────────────────────────────────────┘
```

### 통계 수치 보기 (PIN 필요)

1. 화면에 보이는 **🔒 잠금 해제** 아이콘 클릭
2. PIN 입력 다이얼로그 표시
3. **PIN** 입력 (관리자에게 전달받은 4자리 숫자)
4. **확인** 클릭

✅ PIN 입력 후 → 매출, 예약, 방문객 수 표시

### 기간별 보기

좌상단에서 기간 선택:

| 버튼 | 범위 | 예시 |
|------|------|------|
| **오늘** | 당일 00:00 ~ 23:59 | 2026.04.13 |
| **이번 주** | 월 ~ 일 | 2026.04.07 ~ 04.13 |
| **이번 달** | 1일 ~ 말일 | 2026.04.01 ~ 04.30 |

### 차트 보기

- **막대 그래프**: 일별 매출액 표시
- **클릭 기능**: 특정 날짜의 막대를 클릭하면 `/reservations?date=2026-04-13` 페이지로 이동
  → 해당 날짜의 모든 예약 목록 확인 가능

## 예약 관리

**경로**: 좌측 메뉴 > 예약 관리 또는 대시보드 차트에서 날짜 클릭

### 예약 목록 보기

#### 기본 화면
```
┌─────────────────────────────────────────┐
│ 예약 관리                                │
│ [당일] [금주] [이번달]  [달력]  [검색]    │
├─────────────────────────────────────────┤
│ No. │ 예약자 │ 전화 │ 날짜 │ ... │ 관리 │
├─────┼────────┼──────┼─────┼─────┼────┤
│ 1   │ 홍길동 │ 010- │ ... │ ... │ ✏️ 🗑️ │
│ 2   │ 김영희 │ 010- │ ... │ ... │ ✏️ 🗑️ │
│ ... │        │      │     │     │    │
└─────────────────────────────────────────┘
```

#### 기간 필터링

좌상단 **퀵 버튼** 사용:

- **당일**: 오늘 예약만 표시
- **금주**: 이번 주 월요일 ~ 일요일
- **이번달**: 1일 ~ 말일
- **달력 아이콘**: 특정 날짜 범위 선택

**예시**:
```
오늘 (2026.04.13) → 2026.04.13의 예약만 표시
금주 → 2026.04.07 ~ 04.13 예약 표시
이번달 → 2026.04.01 ~ 04.30 예약 표시
```

#### 검색

상단 **검색창**에 입력:

- **예약자명**: "홍길동" 입력 → 홍길동의 모든 예약 표시
- **전화번호**: "01012345678" 입력 → 해당 번호 예약 표시
- **메모**: 특정 메모 내용으로 검색

**실시간 필터링**: 입력하면 즉시 결과 반영

#### 정렬

테이블 **컬럼 헤더** 클릭하여 정렬:

- **예약자명**: A → Z / Z → A
- **날짜**: 오래된 순 / 최신 순
- **금액**: 낮은 순 / 높은 순

### 예약 추가

#### 단계별 진행

1. **우측 상단 "새 예약 추가" 버튼** 클릭
2. **예약 정보 입력** (필수 항목은 별표 *):
   ```
   - 예약자명 * (예: 홍길동)
   - 전화번호 * (예: 010-1234-5678)
   - 이메일 (선택)
   - 예약 타입 * (예: Single / Double / Group)
   - 체크인 날짜 * (달력에서 선택)
   - 체크아웃 날짜 * (체크인 후 날짜 선택)
   - 인원수 * (기본값: 1)
   - 숙소 * (드롭다운에서 선택)
   - 객실 타입 * (선택한 숙소의 객실 중 선택)
   - 총 금액 * (예: 300000)
   - 메모 (특이사항 입력)
   ```

3. **저장** 버튼 클릭
4. ✅ "예약이 저장되었습니다" 메시지 표시

#### 입력 팁

- **인원수**: 숫자만 입력 (예: 4)
- **금액**: 쉼표 없이 숫자만 입력 (예: 350000)
- **날짜**: 달력 아이콘 클릭하여 선택 (금/토요일은 빨간색으로 강조 표시)
- **숙소/객실**: 드롭다운 클릭하여 목록에서 선택
- **이용권**: 이용권 관리 페이지에서 설정한 표시 순서대로 노출됨

### 예약 수정

1. **해당 예약 행의 ✏️ (연필) 아이콘** 클릭
2. **정보 수정**
3. **저장** 클릭

✅ 수정 완료

### 예약 상태 관리

#### 예약금 확인 (Deposit Paid)

```
☐ → 미결제
☑ → 결제 완료 (날짜 자동 기록)
```

**동작**:
1. 해당 예약의 **체크박스** 클릭
2. 즉시 데이터베이스 저장
3. 날짜는 자동으로 현재 날짜 기록

#### 차액 결제수단 (Balance Payment Method)

```
드롭다운 선택:
├─ 미정 → 현장결제 혹은 추후 결정
├─ 계좌이체 → 계좌 이체로 결제
├─ 카드 결제 → 신용/체크카드로 결제
├─ 현금 결제 → 현금으로 결제
├─ 플레이스 결제 → 네이버 플레이스 등 플레이스 채널 결제
├─ 스토어 결제 → 스토어팜/마켓 등 커머스 결제
└─ 소셜 결제 → 소셜커머스 채널 결제
```

**동작**:
1. **드롭다운 클릭**
2. **결제수단 선택**
3. 즉시 저장

#### 고객 방문 상태 (Visited)

```
☐ → 방문 전
☑ → 방문 완료 (행이 초록색으로 강조)
```

**동작**:
1. **체크박스 클릭**
2. 행이 초록색으로 변함
3. 즉시 저장

### 예약 삭제

1. **해당 예약 행의 🗑️ (휴지통) 아이콘** 클릭
2. **"정말 삭제하시겠습니까?" 확인** 클릭
3. ✅ 삭제 완료

⚠️ **주의**: 삭제는 취소 상태로 변환되어 이력이 보관됩니다.

## 숙소 관리

**경로**: 좌측 메뉴 > 숙소 관리

### 숙소 목록 보기

```
┌──────────────────────────────────┐
│ 숙소 관리                        │
├──────────────────────────────────┤
│ No. │ 숙소명 │ 방 종류 │ ... │ 관리 │
├─────┼────────┼────────┼─────┼────┤
│ 1   │ 길조   │ 2인실  │ ... │ ✏️ 🗑️ │
│     │        │ 4인실  │     │    │
│ 2   │ 한옥   │ 6인실  │ ... │ ✏️ 🗑️ │
└──────────────────────────────────┘
```

### 숙소 추가

1. **우측 상단 "새 숙소 추가" 버튼** 클릭
2. **숙소 정보 입력**:
   ```
   - 숙소명 * (예: 길조호텔)
   - 연락처 (예: 031-123-4567)
   - 상세 정보 (예: 산 위치, 조용한 환경)
   ```

3. **객실 타입 추가**:
   - **추가 버튼** 클릭
   - **객실 이름 입력** (예: 2인실, 4인실, 더블룸)
   - 필요한 만큼 반복

4. **저장** 클릭

✅ 숙소가 목록에 추가됨

**예시**:
```
숙소: 길조호텔
├─ 2인실
├─ 4인실
└─ 6인실
```

### 숙소 수정

1. **해당 숙소의 ✏️ 아이콘** 클릭
2. **정보 수정**:
   - 숙소명, 연락처, 상세 정보 변경 가능
   - 객실도 추가/제거 가능
3. **저장** 클릭

✅ 수정 완료

### 숙소 삭제

1. **해당 숙소의 🗑️ 아이콘** 클릭
2. **확인**
3. ✅ 삭제 완료

⚠️ **주의**: 숙소를 삭제하면 관련 객실 정보도 함께 삭제됩니다.

## 이용권 관리

**경로**: 좌측 메뉴 > 이용권 관리

### 이용권 목록 보기

- 등록된 모든 이용권을 표시 순서대로 노출
- 표시 항목: No., 이용권 명칭, 가격, 관리(수정/삭제)

### 이용권 추가

1. **우측 상단 "이용권 추가" 버튼** 클릭
2. **이용권 명칭, 가격 입력**
3. **저장** 클릭
4. ✅ 새 이용권은 목록 **맨 끝**에 추가됨

### 순서 변경 (드래그앤드롭)

자주 사용하는 이용권을 상단으로 끌어올려 빠르게 선택할 수 있습니다.

1. **각 행 좌측 ≡ (손잡이) 아이콘**을 클릭한 채 드래그
2. 원하는 위치에 놓기 (drop)
3. ✅ 즉시 새 순서로 저장 → 예약 폼의 이용권 드롭다운에도 동일 순서로 반영

💡 **팁**: 데스크탑/모바일 모두 동작합니다. 모바일에서는 손가락으로 길게 누른 뒤 드래그하세요.

### 이용권 수정 / 삭제

- **수정**: 행의 ✏️ (연필) 아이콘 → 명칭/가격 변경 → 저장 (순서는 유지됨)
- **삭제**: 행의 🗑️ (휴지통) 아이콘 → 확인

⚠️ **주의**: 이용권을 삭제해도 이미 발생한 예약 데이터에는 영향을 주지 않습니다(예약에 기록된 이용권 명/금액은 보존).

## 영업 현황 조회

**경로**: 좌측 메뉴 > 영업 현황

### 화면 구성

```
┌────────────────────────────────┐
│ 영업 현황                       │
│ [오늘] [이번 주] [이번 달]     │
├────────────────────────────────┤
│ 🔒 PIN 입력하여 잠금 해제      │
├────────────────────────────────┤
│ 매출 추이 (차트)                │
├────────────────────────────────┤
│ 상세 내역                        │
│ (최근 5건의 거래 기록)          │
└────────────────────────────────┘
```

### PIN으로 잠금 해제

1. **화면의 🔒 아이콘 또는 영역** 클릭
2. **PIN 입력 다이얼로그** 표시
3. **PIN 입력** (4자리 숫자, 관리자 제공)
4. **확인** 클릭

✅ PIN 입력 후 → 통계 및 차트 표시

### 기간별 통계 보기

상단 버튼에서 선택:

- **오늘**: 당일 통계
- **이번 주**: 이번 주 통계
- **이번 달**: 이번 달 통계

**표시 항목**:
- 총 매출 (₩)
- 예약 건수 (건)
- 평균 결제액 (₩)

### 매출 추이 차트

- **형태**: 막대 그래프
- **X축**: 날짜 (일/주/월 단위)
- **Y축**: 매출액 (₩)
- **특징**: 취소된 예약 제외

### 상세 내역 확인

테이블에 최근 5건의 거래 기록:

| 날짜 | 유형 | 예약자 | 금액 | 상태 |
|------|------|--------|------|------|
| 2026.04.13 | Single | 홍길동 | ₩300,000 | 완료 |
| ... | ... | ... | ... | ... |

## 자주 하는 질문

### Q1. PIN을 잊어버렸어요.
**A**: 관리자에게 문의하세요. 관리자가 PIN을 초기화해드릴 수 있습니다.

### Q2. 로그인이 안 돼요.
**A**: 
- 이메일 주소가 맞는지 확인하세요.
- 비밀번호를 정확히 입력했는지 확인하세요.
- 캡스락이 켜져있지는 않은지 확인하세요.
- 여전히 안 되면 관리자에게 문의하세요.

### Q3. 예약을 수정했는데 저장되지 않았어요.
**A**: 
- 필수 항목(*)을 모두 입력했는지 확인하세요.
- 인원수와 금액은 숫자만 입력해야 합니다.
- 체크아웃 날짜가 체크인 날짜보다 뒤여야 합니다.
- 저장 버튼을 다시 클릭해보세요.

### Q4. 예약을 실수로 삭제했어요.
**A**: 현재는 삭제된 예약을 복구할 수 없습니다. 관리자에게 데이터베이스 복구를 요청하세요.

### Q5. 검색이 안 되는 것 같아요.
**A**: 
- 정확한 이름이나 전화번호를 입력했는지 확인하세요.
- 공백이 포함되어 있는지 확인하세요.
- 기간 필터를 해제해보세요 (검색과 기간 필터를 함께 사용하면 범위가 좁혀집니다).

### Q6. 숙소를 삭제했는데 예약에는 여전히 보여요.
**A**: 숙소 삭제 후 이미 생성된 예약은 유지됩니다. 예약을 개별적으로 삭제해야 합니다.

### Q7. 모바일(스마트폰)에서 사용할 수 있나요?
**A**: 네. 모바일 반응형 UI를 지원합니다. 하단 탭 바로 페이지 이동이 가능하고, 예약/숙소 목록은 카드 형태로 표시됩니다.

### Q8. 다른 사람의 계정으로 로그인할 수 있나요?
**A**: 아니요. 개인 계정으로만 로그인할 수 있습니다. 다른 계정이 필요하면 관리자에게 문의하세요.

### Q9. 데이터가 안전한가요?
**A**: 네. 모든 데이터는 Supabase의 안전한 클라우드 데이터베이스에 저장되며, HTTPS를 통해 암호화되어 전송됩니다.

### Q10. 언제까지의 데이터를 조회할 수 있나요?
**A**: 시스템에 입력된 모든 과거 데이터를 조회할 수 있습니다. 특정 기간 데이터 추출이 필요하면 관리자에게 요청하세요.

### 알림 확인

사이드바(PC) 또는 상단 헤더(모바일)의 **🔔 벨 아이콘** 확인:
- 빨간 배지 숫자 = 미입금 건수
- 배지 없음 = 미입금 건 없음

### 알림 상세 보기

1. **벨 아이콘** 클릭
2. 팝오버에 미입금 목록 표시:
   - **오늘/내일/모레** 뱃지로 긴급도 구분
   - 고객명, 예약 유형, 인원, 미입금액 표시
3. **항목 클릭** → 해당 예약 수정 화면으로 바로 이동

### 알림 조건
- 예약일 **이틀 전**부터 표시
- **예약금 미입금** + **예약 상태** 건만 대상
- 입금 완료 체크 시 알림에서 자동 제거
- 5분마다 자동 갱신

## 모바일 사용법

### 하단 탭 바
화면 하단에 고정된 탭으로 주요 페이지 빠르게 이동:
- 영업현황 / 예약관리 / 이용권 / 숙소관리

### 예약 목록 (모바일)
- 테이블 대신 **카드 형태**로 표시
- 카드에 예약 유형, 고객명, 날짜, 인원, 금액 등 핵심 정보
- **카드 탭** → 수정 다이얼로그 오픈

### 숙소 목록 (모바일)
- 카드 형태로 숙소명, 연락처, 방 종류 표시
- 수정/삭제 버튼 제공
