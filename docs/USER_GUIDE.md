## 시작하기

### 로그인

1. 브라우저에서 시스템 주소로 접속
2. 로그인 페이지에서 **이메일** 입력
3. **비밀번호** 입력
4. **로그인** 버튼 클릭

✅ 로그인 성공 → 대시보드로 자동 이동

### 로그아웃

우측 상단 **프로필 메뉴** → **로그아웃**

## 대시보드 보기

**경로**: 로그인 후 메인 화면 또는 좌측 메뉴 > 대시보드

### 화면 구성

```
┌────────────────────────────────────────┐
│ 영업 현황 대시보드                      │
│ [오늘] [이번 주] [이번 달]              │
├────────────────────────────────────────┤
│ 📊 총 매출        📈 예약        👥 방문객 │
│ ₩ ___,___        ___ 건         ___ 명   │
│ (PIN 잠금 🔒)                          │
├────────────────────────────────────────┤
│ 매출 추이 (차트)                        │
│ [날짜 클릭 시 해당 예약 목록 확인]      │
└────────────────────────────────────────┘
```

### 통계 수치 보기 (PIN 필요)

1. 화면에 보이는 **🔒 잠금 해제** 아이콘 클릭
2. PIN 입력 다이얼로그 표시
3. **PIN** 입력 (관리자에게 전달받은 4자리 숫자)
4. **확인** 클릭

✅ PIN 입력 후 → 매출, 예약, 방문객 수 표시

### 기간별 보기

좌상단에서 기간 선택:

| 버튼 | 범위 | 예시 |
|------|------|------|
| **오늘** | 당일 00:00 ~ 23:59 | 2026.04.13 |
| **이번 주** | 월 ~ 일 | 2026.04.07 ~ 04.13 |
| **이번 달** | 1일 ~ 말일 | 2026.04.01 ~ 04.30 |

### 차트 보기

- **막대 그래프**: 일별 매출액 표시
- **클릭 기능**: 특정 날짜의 막대를 클릭하면 `/reservations?date=2026-04-13` 페이지로 이동
  → 해당 날짜의 모든 예약 목록 확인 가능

## 예약 관리

**경로**: 좌측 메뉴 > 예약 관리 또는 대시보드 차트에서 날짜 클릭

### 예약 목록 보기

#### 기본 화면
```
┌─────────────────────────────────────────┐
│ 예약 관리                                │
│ [당일] [금주] [이번달]  [달력]  [검색]    │
├─────────────────────────────────────────┤
│ No. │ 예약자 │ 전화 │ 날짜 │ ... │ 관리 │
├─────┼────────┼──────┼─────┼─────┼────┤
│ 1   │ 홍길동 │ 010- │ ... │ ... │ ✏️ 🗑️ │
│ 2   │ 김영희 │ 010- │ ... │ ... │ ✏️ 🗑️ │
│ ... │        │      │     │     │    │
└─────────────────────────────────────────┘
```

#### 날짜 필터 기준 (방문일 / 등록일)

날짜 필터의 **기준**을 두 가지로 전환할 수 있습니다.

- **방문일** (기본값): 손님이 방문하기로 한 날짜로 필터. 평소 일정 확인 용도.
- **등록일**: 시스템에 예약을 **입력한 날짜(시각 포함)** 로 필터. 검토용.
  - 예) 오늘 10건을 입력했는데 방문 날짜가 다 제각각인 경우 → `등록일 + 오늘` 클릭 시 오늘 입력한 10건이 한 번에 리스트업됨.

토글은 좌상단 퀵 버튼 왼쪽의 **[방문일] [등록일]** 버튼으로 전환합니다.

#### 기간 필터링

좌상단 **퀵 버튼** 사용:

- **오늘**: 오늘 예약만 표시
- **이번주**: 이번 주 월요일 ~ 일요일
- **이번달**: 1일 ~ 말일
- **달력 아이콘**: 특정 날짜 범위 선택

**하루씩 이동 (◀ / ▶ 버튼)**:

날짜 선택 버튼 **왼쪽에 ◀(어제), 오른쪽에 ▶(내일)** 버튼이 있습니다. 현재 보고 있는 날짜를 하루씩 앞뒤로 넘길 수 있어, 달력을 열지 않고도 어제·내일 예약을 빠르게 확인할 수 있습니다.

- 예) 오늘 예약을 보다가 **▶** 클릭 → 내일 예약, 한 번 더 클릭 → 모레 예약
- 여러 날짜 범위를 선택한 상태에서 눌러도 **범위 폭을 유지**하며 통째로 이동합니다.

> 💡 모바일에서는 오늘/이번주/이번달 버튼이 더 작게 표시되어 화면을 덜 차지합니다.

**예시**:
```
오늘 (2026.04.13) → 2026.04.13의 예약만 표시
이번주 → 2026.04.07 ~ 04.13 예약 표시
이번달 → 2026.04.01 ~ 04.30 예약 표시
▶ 클릭 (2026.04.13 상태) → 2026.04.14 예약 표시
```

#### 검색

상단 **검색창**에 입력:

- **예약자명**: "홍길동" 입력 → 홍길동의 모든 예약 표시
- **전화번호**: "01012345678" 입력 → 해당 번호 예약 표시
- **메모**: 특정 메모 내용으로 검색

**실시간 필터링**: 입력하면 즉시 결과 반영

#### 정렬

테이블 **컬럼 헤더** 클릭하여 정렬:

- **예약자명**: A → Z / Z → A
- **날짜**: 오래된 순 / 최신 순
- **금액**: 낮은 순 / 높은 순

### 예약 추가

#### 단계별 진행

1. **우측 상단 "새 예약 추가" 버튼** 클릭
2. **예약 정보 입력** (필수 항목은 별표 *):
   ```
   - 예약자명 * (예: 홍길동)
   - 전화번호 * (예: 010-1234-5678)
   - 전화번호 (예비) (선택 — `+ 예비 번호` 버튼을 눌러야 나타남)
   - 이메일 (선택)
   - 예약 타입 * (예: Single / Double / Group)
   - 체크인 날짜 * (달력에서 선택)
   - 체크아웃 날짜 * (체크인 후 날짜 선택)
   - 인원수 * (기본값: 1)
   - 숙소 * (드롭다운에서 선택)
   - 객실 타입 * (선택한 숙소의 객실 중 선택)
   - 총 금액 * (예: 300000)
   - 메모 (특이사항 입력)
   ```

3. **저장** 버튼 클릭
4. ✅ "예약이 저장되었습니다" 메시지 표시

#### 입력 팁

- **인원수**: 숫자만 입력 (예: 4)
- **금액**: 쉼표 없이 숫자만 입력 (예: 350000)
- **날짜**: 달력 아이콘 클릭하여 선택 (금/토요일은 빨간색으로 강조 표시)
- **숙소/객실**: 드롭다운 클릭하여 목록에서 선택
- **이용권**: 이용권 관리 페이지에서 설정한 표시 순서대로 노출됨

### 예약 수정

1. **해당 예약 행의 ✏️ (연필) 아이콘** 클릭
2. **정보 수정**
3. **저장** 클릭

✅ 수정 완료

### 완료된 예약 숨기기 (남은 건만 보기)

예약이 많은 날, 이미 처리한 건들 사이에서 **앞으로 올 손님**을 찾기 힘들 때 씁니다.

검색창 오른쪽 **`완료 숨기기`** 버튼을 한 번 누르세요.

```
[👁 완료 숨기기]  →  누르면  →  [👁 완료 41건 숨김]
```

- 완료 처리된 예약이 목록에서 빠집니다. 예) 45건 중 완료 41건이 빠지고 **남은 4건**만 표시
- 버튼에 **숨긴 건수**가 표시되니, 예약이 없어진 게 아니라 숨긴 상태라는 걸 바로 알 수 있습니다
- 다시 누르면 전부 돌아옵니다
- **취소된 예약은 그대로 남습니다** (이미 회색으로 표시되어 구분됩니다)

상단의 **예약 건수·방문자·숙소별 인원**도 숨긴 결과에 맞춰 같이 다시 계산됩니다. 그래서 누르는 순간 "남은 몇 건에 몇 명 오는지"가 바로 나옵니다.

> 💡 완료된 예약이 하나도 없는 날(예: 미래 날짜)에는 버튼이 흐리게 비활성됩니다. 새로고침해도 숨긴 상태는 유지되고 그 화면 주소를 공유할 수 있지만, 처음 들어올 때는 항상 전체가 보입니다.

### 예약금 미입금 건 한눈에 찾기

예약 목록의 **결제 정보** 칸 색만 보면 돈을 받았는지 알 수 있습니다.

```
🟨 호박색  →  예약금 미입금 (받아야 할 돈)
🟩 초록색  →  정산 완료
⬜ 회색    →  진행 중
```

- 호박색 박스는 **왼쪽에 굵은 색 띠**가 붙어서, 목록을 위아래로 훑을 때 바로 눈에 걸립니다
- 예약금 금액 옆에 **`미입금`** 배지도 함께 표시됩니다

> 💡 **중요**: 잔금 결제수단을 이미 입력해 둔 예약이라도, **예약금이 미입금이면 호박색**으로 표시됩니다. 예전에는 이런 건이 초록색으로 보여서 미입금인 걸 놓치기 쉬웠습니다.

모바일에서는 카드의 예약금 줄에 `미입금` 배지가 표시됩니다.

### 픽업 인원 모아보기

목록 툴바의 **🚌 버튼**을 누르면, 지금 조회 중인 기간의 픽업 일정이 **장소별·시간순**으로 모여서 나옵니다.

```
픽업 현황
2026-07-29                          8건 · 36명     [복사]

🚌 가평역                                    36명 · 8건
   08:30   손은진 5명            010-1234-5678
   08:50   조어진 6명            010-2345-6789
   09:00   조광민 5명            010-3456-7890
           정도연 5명            010-4567-8901
   09:30   권민상 5명            010-5678-9012
```

- **같은 시각에 두 팀 이상**이면 시각 아래에 나란히 묶여 나옵니다 (위 09:00처럼)
- 08:50과 09:00처럼 **시간이 비슷한 건들은 자동으로 묶지 않습니다.** 차량 사정에 따라 묶을지 말지는 직접 판단하시라고 시간순으로만 늘어놓았습니다
- 전화번호를 누르면 **바로 전화**가 걸립니다 (휴대폰에서)
- 픽업 시간이 안 적힌 예약은 맨 아래 `시간 미정`으로 모입니다
- 취소된 예약은 빠집니다

**[복사]** 를 누르면 기사님께 그대로 보낼 수 있는 형태로 클립보드에 복사됩니다.

> 날짜를 내일로 맞추고 열면 내일 픽업 준비가 한 번에 정리됩니다. 여러 날짜를 조회하면 날짜별로 나뉘어 표시됩니다.

### 숙소별 인원 한눈에 보기

예약 목록 상단, 방문자·댕댕이 합계 아래에 **숙소별 인원 칩**이 표시됩니다.

```
방문자 86명   댕댕이 2마리
🏠 블링블링 29명 7건   🏠 원코리아 5명 1건   ☀️ 당일 52명 9건
```

- 지금 **조회 중인 기간**의 숙박 예약을 숙소별로 묶어 인원과 건수를 보여줍니다
- 당일 예약은 `☀️ 당일` 칩 하나로 합산됩니다
- 취소된 예약은 빠집니다 (방문자 합계와 같은 기준)
- 칩에 적힌 인원을 모두 더하면 위의 **방문자 합계와 같습니다**

날짜를 오늘로 맞추면 "오늘 블링블링에 몇 명 오는지"가 바로 나오므로, 침구·식사·픽업 준비에 쓰기 좋습니다. 검색이나 결제수단 필터를 걸면 칩도 그 결과에 맞춰 다시 계산됩니다.

> 예약이 있는 숙소만 나타납니다. 모바일에서는 칩 줄을 좌우로 밀어서 볼 수 있습니다.

### 목록에서 숙소 바로 지정하기

숙박 예약은 대부분 블링블링이라, 예약 목록의 **숙소** 칸에서 곧바로 지정할 수 있습니다.

```
숙소 칸을 클릭 → [🏠 블링블링] / [없음] 중 선택
```

- 선택하면 **즉시 저장**됩니다 (별도 저장 버튼 없음)
- 여러 건을 연달아 블링블링으로 바꿀 때 예약을 하나씩 열지 않아도 됩니다
- **숙박 예약에서만** 드롭다운이 나타납니다. 당일 예약은 숙소가 없으므로 `-`로 표시됩니다

**객실이 있는 숙소는 목록에서 못 바꿉니다.** 남이섬 리버필드·리버스케치, 원코리아처럼 방 종류를 골라야 하는 숙소는 방 배정이 어긋날 수 있어, 예약을 열어 **수정 화면**에서 변경해 주세요. 이런 숙소로 지정된 행은 드롭다운 대신 글자로만 표시됩니다.

> 지금은 PC 목록에서만 지원하며, 모바일 카드에서는 보기만 됩니다.

#### 상태 바꾸기 (생성·수정 공통)

화면 맨 위 **예약 유형** 오른쪽에 **상태 토글**이 있습니다.

```
상태  [예약됨] [완료] [취소됨]
```

- 원하는 상태를 누른 뒤 **저장**을 눌러야 반영됩니다
- 목록에서 상태를 바꿀 때는 즉시 저장되지만, 폼에서는 저장 버튼이 최종 확인 역할을 합니다

💡 **워크인(로드) 손님 팁**: 예고 없이 오셔서 이용까지 마친 손님은, 새 예약을 만들면서 상태를 바로 **완료**로 두고 저장하면 됩니다. 예전처럼 저장한 뒤 목록에서 예약됨 → 완료로 다시 바꿀 필요가 없습니다.

#### 예비 번호 추가하기

예약한 사람과 실제로 오시는 분이 다를 때처럼 번호를 하나 더 남겨야 하면, **전화번호** 라벨 오른쪽의 **`+ 예비 번호`** 를 누르세요.

- 누르면 **전화번호 (예비)** 입력란이 바로 아래 나타납니다
- 필요 없어지면 **삭제**를 눌러 값을 비우고 접을 수 있습니다
- 저장된 예비 번호가 있으면 수정 화면을 열 때 자동으로 펼쳐집니다
- 입력하면 예약 목록에 `예비` 라벨과 함께 표시되고, 검색창에서 이 번호로도 예약을 찾을 수 있으며, 엑셀 내보내기에도 별도 열로 포함됩니다

### 예약 상태 관리

#### 환불금 (Refund)

```
예약금 우측에 환불금 입력란 표시
잔금 = 총 결제금액 − 예약금 + 환불금
```

**언제 쓰나요?**
예약금을 너무 많이 받아서 일부 돌려준 경우에 사용합니다. 예) 예약금 38만원을 받았는데 실제 정산 금액이 34만원이라 4만원을 환불해줬다면:
- 총 결제금액: **340,000원** (최종 정산 금액 그대로)
- 예약금: **380,000원** (실제 입금받은 금액)
- 환불금: **40,000원**
- 잔금: **0원** (자동 계산)

대시보드의 "총 매출"은 자동으로 `예약금 − 환불금`을 실현 매출로 인정하여 정확한 매출이 표시됩니다.

#### 예약금 확인 (Deposit Paid)

```
☐ → 미결제
☑ → 결제 완료 (날짜 자동 기록)
```

**동작**:
1. 해당 예약의 **체크박스** 클릭
2. 즉시 데이터베이스 저장
3. 날짜는 자동으로 현재 날짜 기록

#### 차액 결제수단 (Balance Payment Method)

```
드롭다운 선택:
├─ 미정 → 현장결제 혹은 추후 결정
├─ 계좌이체 → 계좌 이체로 결제
├─ 카드 결제 → 신용/체크카드로 결제
├─ 현금 결제 → 현금으로 결제
├─ 플레이스 결제 → 네이버 플레이스 등 플레이스 채널 결제
├─ 스토어 결제 → 스토어팜/마켓 등 커머스 결제
└─ 소셜 결제 → 소셜커머스 채널 결제
```

**동작**:
1. **드롭다운 클릭**
2. **결제수단 선택**
3. 즉시 저장

#### 고객 방문 상태 (Visited)

```
☐ → 방문 전
☑ → 방문 완료 (행이 초록색으로 강조)
```

**동작**:
1. **체크박스 클릭**
2. 행이 초록색으로 변함
3. 즉시 저장

### 예약 삭제

1. **해당 예약 행의 🗑️ (휴지통) 아이콘** 클릭
2. **"정말 삭제하시겠습니까?" 확인** 클릭

⚠️ **주의**: 삭제는 취소 상태로 변환되어 이력이 보관됩니다.

## 숙소 관리

1. **우측 상단 "새 숙소 추가" 버튼** 클릭

   ```
   - 숙소명 * (예: 길조호텔)
   - 연락처 (예: 031-123-4567)
   - 상세 정보 (예: 산 위치, 조용한 환경)
   ```

3. **객실 타입 추가**:
   - **추가 버튼** 클릭

```
숙소: 길조호텔

└─ 6인실
```

### 숙소 수정

1. **해당 숙소의 ✏️ 아이콘** 클릭
2. **정보 수정**:
   - 숙소명, 연락처, 상세 정보 변경 가능
   - 객실도 추가/제거 가능
3. **저장** 클릭

✅ 수정 완료

### 숙소 삭제

1. **해당 숙소의 🗑️ 아이콘** 클릭
2. **확인**
3. ✅ 삭제 완료

⚠️ **주의**: 숙소를 삭제하면 관련 객실 정보도 함께 삭제됩니다.

### 이용권 목록 보기

- 표시 항목: No., 이용권 명칭, 가격, 관리(수정/삭제)

3. **저장** 클릭

### 순서 변경 (드래그앤드롭)

## 자주 하는 질문

### Q1. PIN을 잊어버렸어요.
**A**: 관리자에게 문의하세요. 관리자가 PIN을 초기화해드릴 수 있습니다.

### Q2. 로그인이 안 돼요.
**A**: 
- 이메일 주소가 맞는지 확인하세요.
- 비밀번호를 정확히 입력했는지 확인하세요.
- 캡스락이 켜져있지는 않은지 확인하세요.
- 여전히 안 되면 관리자에게 문의하세요.

### Q3. 예약을 수정했는데 저장되지 않았어요.
**A**: 
- 필수 항목(*)을 모두 입력했는지 확인하세요.
- 인원수와 금액은 숫자만 입력해야 합니다.
- 체크아웃 날짜가 체크인 날짜보다 뒤여야 합니다.
- 저장 버튼을 다시 클릭해보세요.

### Q4. 예약을 실수로 삭제했어요.
**A**: 현재는 삭제된 예약을 복구할 수 없습니다. 관리자에게 데이터베이스 복구를 요청하세요.

### Q5. 검색이 안 되는 것 같아요.
**A**: 
- 정확한 이름이나 전화번호를 입력했는지 확인하세요.
- 공백이 포함되어 있는지 확인하세요.
- 기간 필터를 해제해보세요 (검색과 기간 필터를 함께 사용하면 범위가 좁혀집니다).

### Q6. 숙소를 삭제했는데 예약에는 여전히 보여요.
**A**: 숙소 삭제 후 이미 생성된 예약은 유지됩니다. 예약을 개별적으로 삭제해야 합니다.

### Q7. 모바일(스마트폰)에서 사용할 수 있나요?
**A**: 네. 모바일 반응형 UI를 지원합니다. 하단 탭 바로 페이지 이동이 가능하고, 예약/숙소 목록은 카드 형태로 표시됩니다.

### Q8. 다른 사람의 계정으로 로그인할 수 있나요?
**A**: 아니요. 개인 계정으로만 로그인할 수 있습니다. 다른 계정이 필요하면 관리자에게 문의하세요.

### Q9. 데이터가 안전한가요?
**A**: 네. 모든 데이터는 Supabase의 안전한 클라우드 데이터베이스에 저장되며, HTTPS를 통해 암호화되어 전송됩니다.

### Q10. 언제까지의 데이터를 조회할 수 있나요?
**A**: 시스템에 입력된 모든 과거 데이터를 조회할 수 있습니다. 특정 기간 데이터 추출이 필요하면 관리자에게 요청하세요.
