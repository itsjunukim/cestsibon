# 쎄시봉 영업관리시스템 - 완전 가이드

쎄시봉 영업관리시스템은 숙박업소의 예약, 매출, 숙소 관리를 통합적으로 제공하는 웹 기반 관리 플랫폼입니다.

## 시스템 개요

### 목적

- 숙박업소 운영진이 예약, 매출, 숙소 정보를 한 곳에서 관리
- 실시간 영업 현황 대시보드 제공
- 직원 계정과 권한 관리
- 민감한 정보 보호를 위한 PIN 기반 잠금 시스템

### 주요 특징

- **PIN 보안**: 매출, 예약 통계 등 민감 정보는 PIN으로 보호
- **다양한 보기**: 일일/주간/월간 통계 조회
- **필터링 & 검색**: 키워드, 기간별 조회 및 정렬
- **실시간 동기화**: Supabase를 통한 즉시 데이터 업데이트
- **접근 제어**: 관리자/직원 권한 구분

---

## 주요 기능

### 1. 대시보드 (/)
**권한**: 모든 사용자

메인 화면에서 한눈에 보는 영업 현황:
- 총 매출 (₩)
- 예약 건수 (건)
- 총 방문객 (명)
- 매출 추이 차트 (일/주/월 선택)

**특징**:
- PIN 입력으로 통계 수치 표시 (미입력 시 마스킹)
- 차트 클릭 시 해당 날짜의 예약 상세 조회 가능
- 기간 선택: 오늘 / 이번 주 / 이번 달

---

### 2. 예약 관리 (/reservations)
**권한**: 모든 사용자

예약 목록 조회, 상태 관리, 새 예약 등록:

#### 주요 기능
- **예약 생성**: 우측 상단 "새 예약 추가" 버튼
- **검색**: 예약자명, 전화번호, 메모 복합 검색
- **필터링**: 
  - 기간별 (당일/금주/이번달)
  - 상태별 (예약/완료/취소)
- **정렬**: 예약자 이름, 날짜 등 컬럼 헤더 클릭

#### 예약 상태 관리
- **예약금 확인**: 체크 시 예약금 납부 날짜 기록
- **차액 결제수단**: 이체/카드/현금 선택
- **고객 방문 여부**: 체크 시 행 강조 표시
- **예약 취소**: 삭제 시 취소 기록 보관

#### 컬럼 가시성 제어
좌측 상단 "열 선택" 버튼으로 보고 싶은 컬럼만 표시

---

### 3. 숙소 관리 (/accommodations)
**권한**: 모든 사용자

숙소 정보 및 객실 타입 관리:

#### 주요 기능
- **숙소 등록**: 우측 상단 "새 숙소 추가" 버튼
- **정보 입력**:
  - 숙소명
  - 연락처
  - 상세 정보
  - 객실 타입 (2인실, 4인실 등)
- **수정**: 연필 아이콘 클릭
- **삭제**: 휴지통 아이콘 클릭 후 확인

#### 객실 타입 관리
- 한 숙소마다 여러 객실 타입 등록 가능
- 예약 시 객실 타입 선택 가능

---

### 4. 영업 현황 (/sales)
**권한**: PIN 입력 필요

매출 상세 분석 및 통계:

#### 주요 기능
- **보기 선택**: 오늘 / 이번 주 / 이번 달
- **통계 표시** (PIN 필요):
  - 총 매출
  - 예약 건수
  - 평균 결제액
- **매출 추이**: 일별 매출 차트
- **상세 내역**: 최근 5건의 거래 기록

#### 잠금 해제
우측 상단의 잠금 아이콘 클릭 → PIN 입력 → 통계 표시

---

### 5. 직원 관리 (/admin/users)
**권한**: 관리자 전용

직원 계정 생성, 조회, 삭제:

#### 주요 기능
- **계정 생성**: 우측 상단 "새 직원 등록" 버튼
  - 이메일
  - 비밀번호 (최소 6자)
  - 이름
  - 전화번호
  - 권한 (직원/관리자)
- **계정 조회**: 전체 직원 목록 표시
- **계정 삭제**: 휴지통 아이콘 클릭 후 확인

#### 권한 구분
- **직원**: 기본 기능 접근 (예약, 숙소, 매출 조회)
- **관리자**: 직원 관리 추가 접근

## 사용 가이드

### 첫 로그인

1. 로그인 페이지에서 이메일/비밀번호 입력
2. 대시보드로 자동 이동

### PIN 설정 및 변경

**현재**: 시스템 기본 PIN이 설정되어 있습니다.
- 관리자에게 문의하여 PIN 변경 가능

### 예약 추가 (상세)

1. `/reservations` 페이지 이동
2. "새 예약 추가" 버튼 클릭
3. 예약 정보 입력:
   - 예약자명, 전화번호
   - 체크인/체크아웃 날짜
   - 객실 타입, 인원수
   - 총 금액
4. "예약 저장" 클릭

### 예약 수정

1. 예약 목록에서 해당 행의 연필 아이콘 클릭
2. 정보 수정
3. "저장" 클릭

### 예약 취소

1. 예약 목록에서 해당 행의 휴지통 아이콘 클릭
2. "정말 취소하시겠습니까?" 확인
3. 취소 완료 (이력 보관됨)

## 기술 사양

### 기술 스택

| 항목 | 기술 |
|------|------|
| 프레임워크 | Next.js 14 (React 18) |
| 언어 | TypeScript |
| 스타일링 | Tailwind CSS |
| 상태관리 | TanStack React Query |
| 데이터베이스 | Supabase (PostgreSQL) |
| 폼 | React Hook Form + Zod |
| UI 컴포넌트 | Shadcn/ui |
| 날짜 | date-fns |

### 환경 변수

```env
NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

### 빌드 및 실행

```bash
# 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build

# 프로덕션 실행
npm start

# 린트
npm run lint
```

### 디렉토리 구조

```
src/
├── app/                 # Next.js 페이지
│   ├── page.tsx        # 대시보드
│   ├── reservations/   # 예약 관리
│   ├── accommodations/ # 숙소 관리
│   ├── sales/          # 영업 현황
│   ├── admin/users/    # 직원 관리
│   └── login/          # 로그인
├── components/         # React 컴포넌트
│   ├── ui/            # UI 기본 컴포넌트
│   └── *.tsx          # 기능별 컴포넌트
├── lib/               # 유틸리티 함수
│   └── supabase.ts    # DB 클라이언트
└── types/             # TypeScript 타입
```
