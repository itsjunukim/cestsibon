## 로그인 문제

### 증상 1: "이메일 또는 비밀번호가 잘못되었습니다"

**원인**:
- 이메일 오타
- 비밀번호 오타
- 계정이 존재하지 않음
- 계정이 비활성화됨

**해결**:
1. **이메일 확인**:
   - 대문자/소문자 구분
   - 공백 확인
   - 올바른 이메일 주소인지 재확인

2. **비밀번호 확인**:
   - 대문자/소문자 구분
   - 캡스락 해제 확인
   - 공백 없는지 확인

3. **계정 확인**:
   - 관리자에게 계정이 생성되었는지 확인
   - 정확한 이메일로 계정을 만들었는지 확인

4. **브라우저 캐시 비우기**:
   ```
   Chrome/Edge: Ctrl+Shift+Delete (또는 Cmd+Shift+Delete)
   Firefox: Ctrl+Shift+Delete (또는 Cmd+Shift+Delete)
   Safari: Preferences > Privacy > Manage Website Data > Remove All
   ```

5. **시크릿 창에서 시도**:
   - Chrome: Ctrl+Shift+N
   - Firefox: Ctrl+Shift+P
   - Safari: Cmd+Shift+N

**여전히 안 됨**:
- 관리자에게 문의하여 계정 확인 요청

---

### 증상 2: "연결할 수 없습니다"

**원인**:
- 인터넷 연결 끊김
- 서버 다운
- 방화벽 차단

**해결**:
1. **인터넷 연결 확인**:
   ```bash
   ping google.com
   ```
   응답이 없으면 인터넷 문제

2. **다른 웹사이트 시도**:
   - 다른 사이트가 열리는지 확인
   - 열리면 서버 문제
   - 안 열리면 인터넷 문제

3. **VPN 확인**:
   - VPN이 활성화되면 접속 불가능할 수 있음
   - VPN 비활성화 후 시도

4. **방화벽 확인**:
   - 회사 방화벽이 해당 사이트를 차단하는지 확인
   - IT 부서에 허용 요청

---

### 증상 3: "세션이 만료되었습니다"

**원인**:
- 24시간 이상 미사용
- 세션 토큰 만료
- 다른 기기에서 로그인

**해결**:
1. **다시 로그인**:
   ```
   이메일 입력 → 비밀번호 입력 → 로그인
   ```

2. **자동 로그인 활성화** (선택):
   - 로그인 페이지의 "이 기기에서 계속 로그인" 체크 (향후 추가 예정)

## 데이터 저장 문제

### 증상 1: "저장을 눌렀는데 데이터가 안 저장됨"

**원인**:
- 필수 항목 미입력
- 네트워크 오류
- 데이터 유효성 검사 실패

**해결**:
1. **필수 항목 확인** (별표 * 표시):
   ```
   예약 생성 예시:
   ✓ 예약자명
   ✓ 전화번호
   ✓ 체크인 날짜
   ✓ 체크아웃 날짜
   ✓ 숙소 선택
   ✓ 객실 타입
   ✓ 총 금액
   ```

2. **데이터 형식 확인**:
   - **금액**: 숫자만 입력 (예: 300000, 쉼표 X)
   - **전화번호**: "-" 포함 또는 숫자만 (예: 010-1234-5678 또는 01012345678)
   - **날짜**: 달력에서 선택 (수동 입력 X)

3. **날짜 검증**:
   - 체크아웃 날짜 > 체크인 날짜
   - 과거 날짜는 선택 불가 (일부 경우)

4. **네트워크 확인**:
   - 인터넷 연결 속도 확인
   - 대역폭 부족하면 다시 시도

5. **브라우저 콘솔 확인** (개발자용):
   ```
   F12 → Console 탭 → 오류 메시지 확인
   ```

---

### 증상 2: "저장 중... 버튼이 계속 로딩됨"

**원인**:
- 네트워크 느림
- 서버 오류
- 브라우저 막힘

**해결**:
1. **로딩 기다리기**:
   - 최대 30초까지 기다리기
   - 느린 네트워크에서는 더 오래 걸릴 수 있음

2. **페이지 새로고침**:
   - Ctrl+R (또는 Cmd+R)
   - 저장되었는지 확인

3. **다시 시도**:
   - 저장을 다시 클릭
   - 다시 시도해도 안 되면 [데이터 저장 문제](#데이터-저장-문제)로 넘어가기

4. **브라우저 재시작**:
   - 브라우저 종료
   - 5초 대기
   - 브라우저 재시작

---

### 증상 3: "삭제 후 데이터가 여전히 보여요"

**원인**:
- 데이터베이스 캐시 미업데이트
- 브라우저 캐시

**해결**:
1. **페이지 새로고침**:
   - Ctrl+R (또는 Cmd+R)
   - F5 키
   - 브라우저 새로고침 버튼 클릭

2. **캐시 비우기**:
   ```
   Ctrl+Shift+Delete → 캐시된 이미지 및 파일 선택 → 삭제
   ```

3. **다른 페이지 방문 후 복귀**:
   - 다른 페이지 이동
   - 다시 원래 페이지로 돌아오기

## PIN 문제

### 증상 1: "PIN을 입력해도 안 먹어요"

**원인**:
- 잘못된 PIN
- PIN 입력 칸 포커스 안 됨
- 시스템 버그

**해결**:
1. **PIN 재확인**:
   - 관리자에게 PIN이 정확한지 확인
   - 기본 PIN: 1234

2. **입력 다시 시도**:
   - PIN 입력 칸 클릭
   - 숫자 다시 입력
   - Enter 또는 확인 버튼 클릭

3. **숫자만 입력**:
   - PIN은 숫자만 (알파벳, 특수문자 X)
   - 예: 1234 (O), 12-34 (X)

4. **캡스락/다른 언어 확인**:
   - 영문 입력 모드 확인
   - 숫자 입력 모드 확인

---

### 증상 2: "PIN을 입력했는데 자꾸 다시 묻네요"

**원인**:
- 세션 시간 초과
- 다른 페이지에서 돌아옴
- 시스템 버그

**해결**:
1. **페이지 새로고침**:
   - F5 또는 Ctrl+R

2. **다시 로그인**:
   - 로그아웃 후 다시 로그인
   - 그 후 PIN 입력

3. **브라우저 재시작**:
   - 브라우저 완전 종료
   - 다시 열기
   - 로그인 → PIN 입력

---

### 증상 3: "PIN을 잊어버렸어요"

**해결**:
- **일반 사용자**: 관리자에게 문의
- **관리자**: 시스템 설정 확인 ([관리자 가이드](ADMIN_GUIDE.md#pin-관리) 참조)

---

## 성능 문제

### 증상 1: "페이지가 너무 느려요"

**원인**:
- 느린 인터넷
- 많은 데이터 조회
- 브라우저 메모리 부족

**해결**:
1. **네트워크 속도 확인**:
   ```
   측정 사이트: speedtest.net
   요구사항: 5Mbps 이상 권장
   ```

2. **필터링으로 데이터 줄이기**:
   - 기간 선택 (당일/금주/이번달)
   - 상태 필터링
   - 검색 키워드 입력

3. **브라우저 최적화**:
   - 불필요한 탭 닫기
   - 브라우저 캐시 비우기
   - 확장 프로그램 비활성화

4. **다른 브라우저 시도**:
   - Chrome (권장)
   - Firefox
   - Edge

5. **다른 기기 시도**:
   - 데스크톱/노트북
   - 다른 네트워크 (와이파이/모바일)

---

### 증상 2: "특정 페이지만 느려요"

**원인**:
- 해당 페이지의 쿼리가 무거움
- 대량의 데이터 로드

**해결**:
1. **필터링 강화**:
   - 기간을 더 좁혀서 조회
   - 상태별로 필터링
   - 검색으로 특정 데이터만 조회

2. **페이지 새로고침**:
   - F5 또는 Ctrl+R
   - 브라우저 뒤로가기 → 다시 진행

3. **캐시 비우기**:
   ```
   Ctrl+Shift+Delete → 모든 데이터 삭제
   ```

## 검색 문제

### 증상 1: "검색해도 결과가 안 나와요"

**원인**:
- 정확한 검색어 아님
- 검색 범위가 필터에 의해 제한됨
- 검색 조건 미충족

**해결**:
1. **검색어 확인**:
   - 정확한 이름이나 번호인지 확인
   - 일부만 입력해보기 (예: "홍" 검색)
   - 공백 제거

2. **필터 확인**:
   - 기간 필터를 넓혀보기
   - "모든 상태" 선택으로 상태 필터 해제
   - 특정 상태만 선택되어 있지 않은지 확인

3. **예시**:
   ```
   검색: "홍길동" + 기간 필터: "당일"
   → 결과 없음
   
   해결: 기간 필터를 "금주"로 변경
   → 결과 표시됨
   ```

---

### 증상 2: "검색 결과가 너무 많아요"

**해결**:
1. **더 정확한 검색어 입력**:
   - 전체 이름 입력 (일부 대신)
   - 전화번호 뒷자리 입력

2. **필터로 범위 좁히기**:
   - 기간 선택 (당일/금주/이번달)
   - 상태별 필터링
   - 여러 조건 조합

3. **정렬로 찾기**:
   - 컬럼 헤더 클릭하여 정렬
   - 최신순/오래된순 선택

## 테이블 및 표시 문제

### 증상 1: "컬럼이 보이지 않아요"

**원인**:
- 컬럼 가시성이 비활성화됨

**해결**:
1. **컬럼 설정 확인**:
   - 좌상단 "열 선택" 아이콘 클릭
   - 보고 싶은 컬럼 체크
   - 저장

---

### 증상 2: "테이블이 깨져 보여요" (모바일)

**원인**:
- 모바일 화면이 너무 좁음
- 데스크톱용으로 설계됨

**해결**:
1. **데스크톱 사용 권장**:
   - 태블릿 (가로 방향)
   - 노트북/데스크톱

2. **모바일 필요시**:
   - 가로 방향으로 회전
   - 브라우저 확대 축소 (Ctrl+- 또는 Ctrl++)

- 필요시 해당 예약을 개별 삭제

**원인**:

   - F5 또는 Ctrl+R

2. **다른 페이지 방문 후 돌아오기**:
   - 다른 메뉴 이동
   - 다시 예약 페이지로 이동

- 백업 필요

2. **관리자에게 백업 복구 요청**:

## 브라우저별 문제

### Chrome 문제

**자주 발생**:
- 캐시 때문에 이전 버전 표시

**해결**:
```
Ctrl+Shift+Delete → 캐시된 이미지 및 파일 선택 → 삭제
```

### Firefox 문제

**자주 발생**:
- 캐시 업데이트 느림

**해결**:
```
Ctrl+Shift+Delete → 모든 항목 선택 → 현재 시간 선택 → 삭제
```

### Safari 문제 (Mac)

**자주 발생**:
- 로컬 스토리지 문제

**해결**:
```
Preferences > Privacy > Manage Website Data > 해당 사이트 선택 > Remove
```

### Edge 문제

**자주 발생**:
- Chrome과 유사한 캐시 문제

**해결**:
```
Ctrl+Shift+Delete → 캐시된 이미지 및 파일 선택 → 지금 삭제
```

## 최후의 해결책

위의 모든 방법이 실패했을 경우:

### 1단계: 브라우저 캐시 전체 삭제
```
시크릿 창 열기 → 해당 사이트에서 시도
```

### 2단계: 브라우저 재설치
```
Chrome 완전 제거 → 재설치
또는 다른 브라우저 사용 (Firefox, Edge 등)
```

### 3단계: 네트워크 재설정
```
WiFi 연결 해제 → 다시 연결
또는 모바일 핫스팟으로 시도
```

### 4단계: 관리자 문의
```
위의 모든 방법 실패 시 관리자에게 문의
스크린샷과 함께 정확한 증상 설명 제공
```

- [ ] 다른 브라우저에서도 재현되는지 확인

- [ ] 데이터 형식 정확

## 지원 받기

**문제 해결 안 되면**:

1. **정보 수집**:
   - 스크린샷 (오류 메시지)
   - 사용 중인 브라우저 정보
   - 문제 발생 시간
   - 반복 재현 방법

2. **관리자에게 보고**:
   - 이메일: admin@example.com
   - 전화: (관리자 연락처)

3. **긴급 상황**:
   - 관리자 직접 연락
   - 즉시 대응 필요시
