# 쎄시봉 영업관리시스템 - 관리자 기능 고도화 Task Plan

이 문서는 AI 어시스턴트(Antigravity)와 바이브 코딩 방식으로 업무를 진행하기 위한 기능별 체크리스트입니다. 완료된 항목은 체크(`[x]`) 처리합니다.

## Phase 1. 스키마 및 DB 계층 업데이트 
- [x] `reservations` (또는 관련 스키마) 테이블 내 상태값 관리 필드 확인 및 추가 (요구사항 1, 4, 7)
  - [x] 예약금 확인 (`is_deposit_paid` boolean, `deposit_paid_date` date/timestamp)
  - [x] 차액 결제수단 (`balance_payment_method` varchar: 이체/카드/현금)
  - [x] 매장 방문 체크 (`is_visited` boolean)
- [x] 취소 관리 전략 확정 (소프트 삭제 컬럼 사용 혹은 별도 취소 테이블 이동) (요구사항 9)
- [x] 관련된 프론트엔드 타입스크립트 인터페이스 (예: `types.ts`) 수정 및 추가 반영

## Phase 2. 관리자 예약 목록 UI/UX 기초 개선 (데이터 테이블)
- [x] 목록 좌측에 넘버링(인덱스) 컬럼 추가 (요구사항 6)
- [x] '예약자 이름' 컬럼 헤더 클릭 시 오름차순/내림차순 정렬 로직 연동 (요구사항 5)
- [x] 관리자가 조회할 컬럼을 켜고/끌 수 있는 기능(Visibility Toggle Select Box 등) 개발 (요구사항 8)

## Phase 3. 상태 관리 UI 및 인터랙션 반영 (Row 데이터 제어)
- [x] **'예약금 확인' 체크박스 기능 구현 (요구사항 1)**
  - [x] 체크박스 ON/OFF 시 `is_deposit_paid` 상태 업데이트
  - [x] 체크 시 화면에 날짜(기본: 당일) 수정 가능한 Date Picker 활성화 표시
- [x] **'차액 결제수단' 드롭다운 메뉴 기능 구현 (요구사항 4)**
  - [x] '이체', '카드', '현금', 미선택 상태 제어 로직 작성
- [x] **'고객 방문 상태 관리' 체크박스 구현 (요구사항 7)**
  - [x] 방문(체크박스 선택) 시, 행 단위로 구분이 가도록 CSS 하이라이트(색상/스타일) 적용

## Phase 4. 예약 조회 및 필터 고도화
- [x] 예약 목록에 키워드 검색창 추가 (이름, 전화번호, 메모 복합 검색 로직 적용) (요구사항 2)
- [x] 조회 기간 퀵 버튼 UI 추가 및 달력 상태 연동 (당일 / 금주 / 이번달) (요구사항 3)
  - [x] **당일(일간):** 오늘 예약만 필터링
  - [x] **주간:** 해당 주(월~일) 필터링
  - [x] **월간:** 해당 월(1일~말일) 조회 및, 외부 달력 컴포넌트 정보도 함께 업데이트

## Phase 5. 예약 취소 관리 시스템 구축
- [ ] 기존 단순 '삭제' 로직을 "예약 취소" 상태로 변경하여 이력을 보존하도록 수정 (요구사항 9)
- [ ] **[취소 이력 조회]** 별도 페이지 또는 팝업 모달을 통한 관리자 전용 삭제된 이력 뷰어 개발 (요구사항 9)
