## 관리자 권한

### 권한 구분

```
관리자 (Admin)
├── 모든 페이지 접근 가능
├── 직원 계정 CRUD
├── PIN 관리
├── 데이터 조회/수정/삭제
└── 시스템 설정 변경

직원 (Employee)
├── 예약 관리 (조회/생성/수정/삭제)
├── 숙소 관리 (조회)
├── 영업 현황 (PIN 입력 필요)
└── 대시보드 (PIN 입력 필요)
```

### 관리자 계정 확인

**경로**: 직원 관리 페이지

```
권한 컬럼:
├─ 🛡️ 관리자 (Admin) - 관리자 권한
└─ 👤 직원 (Employee) - 일반 권한
```

## 직원 관리

**경로**: 좌측 메뉴 > 관리 > 직원 관리

### 직원 목록 조회

```
┌──────────────────────────────────────┐
│ 직원 계정 관리                        │
│ [새 직원 등록]                       │
├──────────────────────────────────────┤
│ No. │ 이메일   │ 이름 │ 권한 │ 생성일 │
├─────┼──────────┼──────┼──────┼────────┤
│ 1   │ user1@.. │ 홍길동│ 직원 │ 2026-01-15 │
│ 2   │ user2@.. │ 김영희│ 관리자│ 2026-01-20 │
│ ... │          │      │      │        │
└──────────────────────────────────────┘
```

### 직원 추가

1. **우측 상단 "새 직원 등록" 버튼** 클릭
2. **다이얼로그에서 정보 입력**:

   ```
   필수 항목:
   - 이메일: user@company.com
   - 비밀번호: 최소 6자 이상 (강력한 암호 권장)
   - 이름: 홍길동
   - 전화번호: 010-1234-5678 (선택)
   - 권한: 직원 / 관리자 (드롭다운)
   ```

3. **계정 생성** 버튼 클릭
4. ✅ "계정이 생성되었습니다" 메시지 표시

#### 입력 팁

**이메일**:
- 회사 도메인 권장 (예: name@company.com)
- 중복 불가 (이미 가입된 이메일 사용 불가)
- 예: user.name@company.com

**비밀번호**:
- 최소 6자 이상
- 숫자, 대문자, 특수문자 포함 권장
- 직원에게 안전한 방법으로 전달

**권한 선택**:
- **직원 (Employee)**: 기본 운영 권한
- **관리자 (Admin)**: 전체 관리 권한 필요 시

### 직원 정보 수정

⚠️ **현재**: 직원 정보 수정 기능이 없습니다.
- 정보 변경이 필요하면 계정을 삭제 후 새로 생성해야 합니다.

### 직원 삭제

1. **해당 직원 행의 🗑️ (휴지통) 아이콘** 클릭
2. **"계정을 정말 삭제하시겠습니까?" 확인**
3. ✅ 계정 삭제 완료

**삭제 범위**:
- Supabase Auth에서 로그인 계정 삭제
- profiles 테이블에서 프로필 삭제
- ⚠️ 해당 직원이 생성한 예약 데이터는 유지됨

### 직원 비밀번호 초기화

⚠️ **현재**: 관리자가 직접 비밀번호를 초기화할 수 없습니다.
- 직원이 비밀번호를 잊었을 경우:
  1. Supabase 콘솔에서 직접 초기화 (관리자만 가능)
  2. 또는 해당 계정 삭제 후 새로 생성

## 시스템 설정

### PIN 관리

#### PIN 설정

**현재 시스템 PIN**: `1234` (기본값)

**PIN 용도**:
- 대시보드 통계 보호
- 영업 현황 통계 보호
- 민감한 재무 정보 보호

#### PIN 변경 (개발자/관리자)

⚠️ **현재**: UI에서 PIN을 변경할 수 없습니다.

**변경 방법**:
1. Supabase 프로젝트 설정
2. 환경 변수 업데이트
3. 배포

**향후 개선**: 관리자 UI에서 PIN 변경 기능 추가 예정

### 데이터 백업

#### 자동 백업

- **Supabase 자동 백업**: 일일 자동 백업
- **위치**: Supabase 프로젝트 > Backups

#### 수동 백업

필요시 Supabase 콘솔에서 직접 백업:

1. [Supabase 콘솔](https://app.supabase.com) 접속
2. 해당 프로젝트 선택
3. **Database** > **Backups**
4. **Create Backup** 클릭

### 데이터 복구

#### 실수로 삭제한 데이터 복구

1. Supabase 콘솔 접속
2. **Database** > **Backups**
3. 복구하려는 시점의 백업 선택
4. **Restore** 클릭

⚠️ **주의**: 복구 시 복구 시점 이후의 모든 데이터가 사라집니다.

## 자주 하는 질문

### Q1. 새 직원을 추가했는데 로그인이 안 돼요.
**A**: 
- 이메일 주소가 정확한지 확인하세요.
- 비밀번호를 정확히 전달했는지 확인하세요.
- 직원에게 로그인 페이지에서 이메일/비밀번호를 입력하도록 안내하세요.
- 여전히 안 되면 직원 계정을 삭제 후 다시 생성해보세요.

### Q2. 직원을 실수로 삭제했어요.
**A**: 
- 예약 데이터는 남아있으므로 정상 작동합니다.
- 같은 정보로 새 계정을 생성하면 다시 사용 가능합니다.

### Q3. PIN을 잊어버렸어요.
**A**: Supabase 콘솔에서 환경 변수를 확인하세요. PIN 값이 저장되어 있습니다.

### Q4. 특정 날짜의 데이터를 다시 보고 싶어요.
**A**: Supabase 콘솔의 Backups에서 해당 시점의 백업을 확인할 수 있습니다. 복구가 필요하면 Restore 기능을 사용하세요.

### Q5. 직원의 비밀번호를 초기화하고 싶어요.
**A**: 
- 직원 계정을 삭제합니다.
- 같은 이메일과 새 비밀번호로 다시 생성합니다.

### Q6. 권한을 변경하고 싶은데요.
**A**: 
1. 변경할 직원 계정 삭제
2. 같은 이메일과 새로운 권한으로 다시 생성

또는 Supabase 콘솔에서 직접 변경 가능:
```sql
UPDATE profiles 
SET role = 'admin' 
WHERE email = 'user@company.com';
```

### Q7. 전체 데이터를 엑셀로 추출할 수 있나요?
**A**: 현재 UI에서는 지원하지 않습니다. Supabase 콘솔에서 직접 다운로드하거나 API를 통해 추출할 수 있습니다.

### Q8. 삭제한 예약을 복구할 수 있나요?
**A**: 
- **즉시 복구**: 불가능 (현재 기능 없음)
- **백업 복구**: Supabase 백업에서 전체 복구만 가능 (비추천)
- **향후 개선**: 삭제 이력 관리 기능 추가 예정

### Q9. 매달 매출 보고서를 만들어야 하는데요.
**A**: 
1. 영업 현황 페이지에서 "이번 달" 선택
2. 상세 내역 확인
3. 스크린샷 또는 Supabase에서 직접 추출

### Q10. 새로운 기능을 추가하고 싶은데요.
**A**: 개발 팀에 요청하세요. 우선순위를 검토한 후 구현됩니다.

## 문제 해결

### 시스템 접근 불가

**증상**: "페이지를 찾을 수 없습니다" 또는 빈 화면

**해결**:
1. 브라우저 새로고침 (Ctrl+R 또는 Cmd+R)
2. 캐시 비우기 (Ctrl+Shift+Delete)
3. 다른 브라우저에서 시도
4. 여전히 안 되면 시스템 관리자에게 문의

### 데이터가 저장되지 않음

**증상**: 저장 버튼을 눌렀는데 데이터가 남아있지 않음

**해결**:
1. 네트워크 연결 확인
2. 필수 항목 모두 입력했는지 확인
3. 브라우저 콘솔 오류 확인 (F12)
4. 여전히 안 되면 Supabase 상태 확인

### 느린 성능

**증상**: 페이지 로딩이 느리거나 멈춤

**해결**:
1. 네트워크 연결 속도 확인
2. 필터링 조건 제한 (너무 많은 데이터 조회 시)
3. 브라우저 캐시 비우기
4. 다른 기기에서 시도
